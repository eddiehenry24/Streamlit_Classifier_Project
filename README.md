# Interactive Machine Learning Classifier

## Project Overview

This project is an interactive machine learning application built with Python and Streamlit. The application allows users to select a dataset and compare different machine learning classification algorithms.

The goal of the project was to practice working with machine learning models while also learning how to build a simple interactive application that allows users to explore model performance.

## Features

Users can choose from multiple datasets, including:

- Iris
- Breast Cancer
- Wine

Users can also select from several classification algorithms:

- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Random Forest

The application trains the selected model and displays the classification results through an interactive Streamlit interface.

## Technologies Used

- Python
- Streamlit
- scikit-learn
- Machine Learning
- GitHub


Install the required Python packages:

```bash
pip install streamlit scikit-learn
```

Then run the application with:

```bash
streamlit run interface.py
```

The Streamlit application should open automatically in your web browser.
